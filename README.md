# Кастомный словарь для Piper / espeak-ng

Обновленный русский словарь правил с добавленными йотированными фонемами и опцией проставлять ударения через `U+0301`. Необходимо для адекватной работы фонемайзера для piper.

[PR](https://github.com/espeak-ng/espeak-ng/pull/2234) висит в репозитории espeak-ng, но из-за слишком сильного импакта на синтез звука в существующих проектах не был принят. Выставлять правильные значения звуков для фонем (что требуется только для генератора в espeak) — отдельная задача, вникать в которую нет желания.

Если захочется внести изменения и скомпилировать data самостоятельно, в корне репозитория находится `ru_rules` (всё ещё требует оптимизации), а файл фонем можно дёрнуть из PR.

> [!NOTE]
> **Обновление (03.2026):**
> Сделал второй заход по правке фонем, чтоб решить проблему аканья и прочих коварных недочётов. Это, конечно же, немного сломало синтез на существующих моделях, но небольшое дообучение исправит ситуацию. Прикладываю файл фонем `ph_russian` и правил `ru_rules`. Старая версия скомпилированных данных оставлена в отдельном бранче.


## Использование

Скопируйте 5 файлов из каталога `espeak-ng-data` по пути расположения существующих данных. 

**Примеры путей установки:**
* При обучении по стандартному гайду:
  ```bash
  ~/piper1-gpl/src/piper/espeak-ng-data/
  ```
* Если в проекте используется библиотека (внутри venv или по глобальному пути установки):
  ```bash
  .../Lib/site-packages/piper/espeak-ng-data/
  ```
* Для оригинального Piper:
  ```bash
  /usr/local/share/espeak-ng-data/
  ```

После тренировки новые модели используются с этим же набором словарей.

### Интеграция с sherpa-onnx
Также можно применять модификацию работы с [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), использующую следующую схему:
```text
 📁 vits-piper-ru_RU-ruslan-medium
  ├── 📁 espeak-ng-data
  ├── 📄 ru_RU-ruslan-medium.onnx
  └── 📄 tokens.txt
```
С помощью [конвертации](https://huggingface.co/rraaww/ru_piper/blob/main/converter.pyw) вашей модели и замены файлов в `espeak-ng-data` (воспользуйтесь от другой модели) можно собирать свой голос. Протестировано в легковесной [читалке](https://github.com/mitrokun/PiperReader) для Android.


## Чиним Wyoming Piper

В каталоге `wyoming_piper_accent` лежит модифицированный код Wyoming Piper:

* **Разрешение омографов:** Выполняется для списка слов в `homographs.py` с помощью библиотеки [silero stress](https://github.com/snakers4/silero-stress). Для отключения авторасстановки предусмотрен ключ `--no-automatic-stress`.
* **Пользовательский словарь:** Добавлен файл `user.txt`, в котором удобно указать ударения для специфичных слов (имена, названия) под свои нужды. Также с его помощью решается проблема с именами-омографами.
* **Ёфикатор:** Добавлен словарь ёфикатора (~60к замен), который активируется ключом `--yo`. Всё ещё остается около 4к спорных случаев: старайтесь изначально получать правильное значение либо добавляйте проблемные слова в словарь омографов и надейтесь на библиотеку silero. **При подготовке датасетов не забывайте отключать всю автоматику.**
* **Ручная расстановка:** Символ `+` перед гласной позволяет расставлять ударения в ручном режиме. Любая работа с ударениями работает только при замене словаря и использовании моделей, обученных на нём. О процессе рассказывал в этом [видео](ссылка_на_видео).
* **Нормализация:** Используются два файла нормализации. Для русского — работа с ударениями, согласование дробных чисел, %, годов и прочие подобные фиксы. Для английского — попытка конвертации через IPA-фонемы. Звучит плохо (жесткий акцент и чёткие ударения), но лучше того, что выдаёт piper самостоятельно (большая часть фонем переиспользована при обучении, поэтому получается каша).
* **Кеширование голосов:** Добавлена возможность держать несколько голосов в памяти, чтобы избежать потери времени на секундную загрузку модели. Количество активных моделей настраивается через ключ `--max-cached-voices 2`.
* **Паузы:** Вернул возможность добавлять тишину между предложениями: ключ `--sentence-silence 0.2` задаёт верхний лимит, значение выбирается случайно из диапазона 65-100%. Для книжных текстов (несколько переносов строк между главами, тире в начале реплик) используются удлиненные паузы. Специально для [функции](ссылка_на_функцию) озвучивания книг.
* **Оптимизация:** Отказ от временных файлов, все операции происходят в памяти.
* **Интерфейс:** Используется BCP 47 нормализация имён моделей, чтобы они красиво отображались в интерфейсе Home Assistant.


### микрогайд

```bash
# Базовая установка Piper
git clone https://github.com/rhasspy/wyoming-piper.git
cd wyoming-piper
script/setup

# Подготовка к установке silero-stress, CPU-only torch (без CUDA)
./.venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu

# silero-stress — для автоматической расстановки ударений в русском
# eng-to-ipa — для улучшенного контроля преобразования английских слов
./.venv/bin/pip install silero-stress eng-to-ipa num2words

# Скачиваем репо для замены данных
git clone https://github.com/mitrokun/espeak-ng-data.git

# Файлы фонем и словарей. Существующие 4 голоса перестанут корректно работать
# Проверьте используемую версию python, при необходимости измените путь
cp -r ./espeak-ng-data/espeak-ng-data/* ./.venv/lib/python3.*/site-packages/piper/espeak-ng-data/

# Модификация кода
cp -r ./espeak-ng-data/wyoming_piper_accent/2.0+/* ./wyoming_piper/

# Запуск (использую data в домашнем каталоге)
# В качестве примера копируем существующую модель (обучена на актуальных данных) из этого репозитория
cp ./espeak-ng-data/voice/ru_RU-mari-medium* ~/data/

./script/run --voice ru_RU-mari-medium_epoch6399 --uri 'tcp://0.0.0.0:10200' --data-dir ~/data --download-dir ~/data
```

Больше моделей и пара чекпоинтов для быстрого дообучения доступны [тут](https://huggingface.co/rraaww/ru_piper).  
Послушать некоторые из моделей можно [тут](https://www.youtube.com/@%E7%8D%85%E5%AD%90-8k/shorts).

В каталоге `tools` находятся вспомогательный инструментарий для обучения и тестирования.
