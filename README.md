Обновленный русский словарь с добавленными йотированными фонемами. Необходимо для нормального обучения новых голосов.
[PR](https://github.com/espeak-ng/espeak-ng/pull/2234) висит в репозитории espeak-ng, но из-за слишком сильного импакта на синтез звука в существующих проектах не был принят. Высталять правильные значения звуков для фонем - отдельная задача, вникать в которую нет желания.
Дополнительно прилагаю свою актуальную версию словаря ru_rules (всё ешё требует оптимизации), если захочется внести изменения и скомпелировать data самостоятельно (файл фонем можно дернуть из pr).

### Использование:


Скопировать по пути расположения существующих данных, например:
```
~/piper1-gpl/src/piper/espeak-ng-data/
```
Для оригинального пайпер
```
/usr/local/share/espeak-ng-data/
```
После тренировки новые модели используются с этим же набором данных

В voice примеры голосов, дообученные на небольших датасетах
