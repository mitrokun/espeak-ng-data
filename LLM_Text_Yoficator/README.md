### Скрипт для нормализации Ё

Большинство книг игнорирует `ё`, что ухудшает опыт [прослушивания](https://www.youtube.com/watch?v=KbvwVZjDGcQ) синтезированного варианта. 

Воспользовался готовым словаре из проекта [yo](https://github.com/vgiv/yo/) и добавил нейронку, чтоб не делать ручную работу.

Скрипт работает с гугл библиотекой `genai`.  Есть дебажный вывод результатов для каждого запроса, требуется подтвердить все батчи:
```
Батч 7/56 (вхождения 121-140)
◦ ... оказался бы гораздо громче, [чем] оглушительные взрывы за рекой.
• ... глаза, пытаясь понять, в [чём] дело.
• Поскорей бы уж поделили [всё], подумала она со вздохом, ...
◦ ... невыносимое бремя этой жизни [всем] тем, кто Бог знает ...
◦ ... черных клубах дыма, закрывших [небо] и солнце.
◦ ... месте, чтобы видно было [всем] — с коек смотрят ...
• [Всё] это было прекрасно, но ...
◦ [Все] они как бы сливались ...
◦ ... в воздухе, потому что [все] те, чьи души видела ...
• Мария остановилась и [опёрлась] на одну из гранитных ...
• ... и мрачным взглядом — [всё] это было дрожащим, искривленным ...
• ... было дрожащим, искривленным и [чёрно]-белым, словно Мария видела это ...
• ... нормальным сознанием, и, когда [всё] кончилось, испытала большое облегчение.
• ... назад на набережную, где [всё]-таки было немного света.
• И о [чём] она вообще думала?
◦ ... вспомнила, что может предстать [перед] Женихом такой, какой пожелает.
• ... продолжали горящий на ее [щёках] румянец.
◦ Он стоял [перед] ней и молча глядел ...
• ... загадочно улыбаясь и поднимая [сложённые] руки к груди, — ...
• Шварценеггер [всё] так же молча смотрел ...
```

Если доверяете результатам модели — увеличьте очередь и батч в начале скрипта, либо вообще перепишите логику.

Перед запуском вставьте свой апи ключ в скрипт. Скопируйте текст (.txt) в каталог и запускайте обработку:

`py yo.py --b 1984`

Рядом с оригиналом появится  `1984_yo.txt`, а каждое подтверждение будет пересохранять изменения.


`yo_local.py` — локальный вариант для llama.cpp (отключение мышление через `extra_body`). Перед запуском настройте хост, порт, модель. С Gemma4 работает неплохо.
